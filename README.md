# Statistical Appendix Writing Skill

A skill for drafting, revising, and reviewing statistical paper appendices and supplementary proofs. It emphasizes theorem dependencies, notation, assumptions, technical lemmas, citation verification, and concise statistical writing.

The skill's instructions are in [SKILL.md](SKILL.md); supporting examples and references are in [references](references/).

To use the skill with Codex, copy this repository into your Codex skills directory under the name `how-to-write-appendix-of-a-statistical-paper`, then ask Codex to apply it to your statistical appendix or proof.
